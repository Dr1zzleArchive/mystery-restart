# 腾讯云函数（SCF）Web 函数代理（Express 版）

作用：在服务端保存 DeepSeek 的 API Key，前端只调用这个函数，避免 Key 暴露在浏览器里。

## 控制台界面怎么用

你现在看到的是 **Cloud Studio 在线代码编辑器**：

- 左侧是文件树（`app.js`、`package.json`、`scf_bootstrap` 等）；
- 中间是代码；
- 右上角有 **「部署」** 按钮；
- 底部显示「监听端口 9000」。

## 操作步骤

1. 在左侧文件树点开 `app.js`。
2. `Ctrl+A` 全选，删除模板默认代码，粘贴本目录 `app.js` 的完整内容。
3. **不要改** 底部监听端口（保持 `9000`），也不要去动 `scf_bootstrap`。
4. 点右上角 **「部署」**，等它提示部署成功。
5. 回到函数的 **「函数配置」**（或「配置」标签），在「环境变量」里新增：
   - 键：`DEEPSEEK_API_KEY`
   - 值：你的 DeepSeek Key（`sk-...`）
6. 在「函数 URL」配置里：
   - 公网访问：**开启**
   - 内网访问：**关闭**
   - 授权类型：**开放**（CAM 是腾讯云签名鉴权，浏览器用不了）
7. 保存后，复制「函数 URL」（HTTPS 地址）。
8. 回到游戏「设置 → 沉浸模式（AI）→ 代理地址」，粘贴这个 URL。

## 说明

- 前端开启代理模式后，会把这个 URL 当作 DeepSeek 的替身，请求体原样转发，不再需要前端填 Key。
- `DEEPSEEK_API_KEY` 只在腾讯云服务端，浏览器拿不到。
- 授权类型「开放」意味着知道 URL 的人都能调用，建议后续在腾讯云控制台给函数配限流，避免额度被刷爆。
