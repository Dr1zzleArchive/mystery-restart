# 腾讯云函数（SCF）代理搭建步骤（Web 函数版）

作用：在服务端保存 DeepSeek 的 API Key，前端只调用这个函数，避免 Key 暴露在浏览器里。

## 你需要准备

- 已实名认证的腾讯云账号。
- 一个 DeepSeek API Key（`sk-...`）。

## 搭建步骤

1. 登录腾讯云，进入「云函数 SCF」，新建函数。
2. 函数类型选 **Web 函数**，运行环境选 **Node.js 16 或 18**（你已选的 Node 18 Web 模版即可）。
3. 启动文件填 `index.js`，监听端口保持默认 **9000**。
4. 把本目录的 `index.js` 内容粘贴为入口代码，替换模板默认内容。
5. 在「环境变量」新增：
   - 键：`DEEPSEEK_API_KEY`
   - 值：你的 DeepSeek Key（`sk-...`）
6. 在「函数 URL 配置」里：
   - 公网访问：**开启**（GitHub Pages 是公网网站，需要公开访问）。
   - 内网访问：**关闭**。
   - 授权类型：**免鉴权**（先跑通；正式再用限流或鉴权加固）。
7. 保存后，复制生成的「函数 URL」（HTTPS 地址）。
8. 回到游戏「设置 → 沉浸模式（AI）→ 代理地址」，粘贴这个 URL 即可。

## 说明

- 前端开启代理模式后，会把这个 URL 当作 DeepSeek 的替身，请求体原样转发，不再需要前端填 Key。
- 函数里的 `DEEPSEEK_API_KEY` 只在腾讯云服务端，浏览器拿不到。
- 免鉴权意味着知道 URL 的人都能调用，建议后续在腾讯云控制台给函数配限流，避免额度被刷爆。
