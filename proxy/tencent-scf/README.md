# 腾讯云函数（SCF）代理搭建步骤

作用：在服务端保存 DeepSeek 的 API Key，前端只调用这个函数，避免 Key 暴露在浏览器里。

## 你需要准备

- 已实名认证的腾讯云账号。
- 一个 DeepSeek API Key（`sk-...`）。

## 搭建步骤

1. 登录腾讯云，进入「云函数 SCF」。
2. 新建函数，选择：
   - 创建方式：**从头开始**（或"事件函数"）。
   - 函数名称：例如 `mystery-restart-proxy`。
   - 运行环境：**Node.js 16 或 18**。
   - 地域：建议选离你/用户近的，如广州或上海。
3. 把本目录的 `index.js` 内容粘贴为函数入口文件（`index.js`），执行方法保持 `index.main_handler`。
4. 在「环境变量」里新增：
   - 键：`DEEPSEEK_API_KEY`
   - 值：你的 DeepSeek Key（`sk-...`）
5. 配置触发器：新增「API 网关触发」。
   - 请求方法：勾选 `POST`（也建议勾选 `OPTIONS`，用于浏览器跨域预检）。
   - 发布路径：默认 `/` 即可。
   - 如果网关有「开启 CORS / 跨域」开关，请一并打开。
6. 保存后，把生成的 **API 网关访问地址（HTTPS URL）** 复制下来。
7. 回到游戏网页的「设置 → 沉浸模式（AI）→ 代理地址」，粘贴这个 URL 即可。

## 说明

- 前端开启代理模式后，会把这个 URL 当作 DeepSeek 的替身，请求体原样转发，不再需要前端填 Key。
- 函数里的 `DEEPSEEK_API_KEY` 只在腾讯云服务端，浏览器拿不到。
- 建议在腾讯云控制台给 API 网关配一个简单的限流/鉴权，防止被刷额度。
