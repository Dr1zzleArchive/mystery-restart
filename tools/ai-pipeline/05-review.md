# ⑤ AI 复查

**输入**：合并好的完整本子 JSON。
**输出**：问题清单。
**目的**：换一个角度挑刺，找出逻辑漏洞。程序检查只能查格式，查不出“推理是否成立”。

---

## 提示词

```
你是一位挑剔的推理游戏玩家和编辑。下面是一个推理游戏的完整剧本（JSON）。
玩家只能看到：开场对白、嫌疑人表、调查行动中的台词和线索。玩家看不到 truth 和 solution。

请逐项检查，并按“严重 / 一般 / 建议”三个等级列出问题，每条注明位置（如 actions[3].lines[2]）和修改建议：

1. 可推理性：只凭玩家能看到的内容，能否唯一推出每道题的答案？有没有题目必须读过原著才能答？
2. 唯一性：有没有其他嫌疑人也能同样合理地被指认为凶手？
3. 提前泄底：开场或调查台词有没有过早暴露真相？灰羽有没有直接说出答案？
4. 线索一致性：线索的 text 与获得它的行动台词是否一致？truth 里的解释与线索是否矛盾？
5. 题目质量：选择题的干扰项是否合理？填空题的标准答案是否是简短的关键词？aliases 里有没有其实是错误的说法？有没有漏掉明显正确的说法？
6. 原著忠实度：有没有与原著明显矛盾、又没有必要的改动？
7. 文字：有没有超过 40 字的长句、错别字、人物称呼前后不一致？

最后给出一句总体评价：这个本子能否直接上线。

---
剧本 JSON：
{{完整本子 JSON}}
```

---

## 使用提示

- 可以换一个与前几步不同的模型来做复查，更容易发现问题。
- “严重”问题必须修改；修改后重新运行一次 `validate.html`。
